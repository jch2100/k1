# Content Studio — 퍼스널 브랜딩 수익화 커맨드 센터

> 콘텐츠 / 퍼스널 브랜딩으로 수익을 만드는 과정을 **기획 → 제작 → 발행 → 수익화**까지
> 한 곳에서 실행·추적하는 동작하는 MVP. 빌드 도구 없이 브라우저에서 바로 실행됩니다.

이 저장소는 두 가지로 구성됩니다.
1. **수익화 전략 계획** (아래 30/60/90일 로드맵)
2. **그 계획을 매일 실행하는 도구** (Content Studio 웹 앱)

---

## 🚀 실행 방법

의존성 설치가 필요 없습니다. 아래 중 하나면 됩니다.

```bash
# 방법 A) 정적 서버로 실행 (권장)
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속

# 방법 B) 그냥 파일 열기
# 브라우저로 index.html 더블클릭
```

데이터는 브라우저 `localStorage`에 저장됩니다. 사이드바의
**내보내기 / 가져오기**로 백업하거나 다른 기기로 옮길 수 있습니다.

## 🧭 앱 구성

| 화면 | 하는 일 |
|------|---------|
| **대시보드** | 이번 달 수익·발행 진척도, 다가오는 발행, 수익 구성, 주간 실행 체크리스트 |
| **콘텐츠 파이프라인** | 아이디어 → 제작 중 → 예약됨 → 발행됨 칸반 보드로 콘텐츠 관리 |
| **아이디어 인박스** | 떠오르는 아이디어를 빠르게 모으고, 준비되면 파이프라인으로 승격 |
| **수익 추적** | 광고/협찬/구독/강의/제휴별 수익 기록, 최근 6개월 추이 |
| **브랜드 키트** | 타깃·톤·콘텐츠 기둥·플랫폼별 바이오 등 일관된 브랜딩의 기준점 |

## 📈 수익화 전략 — 90일 로드맵

콘텐츠/퍼스널 브랜딩 수익화의 핵심 루프는 단순합니다:
**일관된 발행으로 신뢰(오디언스)를 쌓고 → 그 신뢰를 제품(협찬·구독·강의·제휴)으로 전환.**

### Phase 1 (0–30일) — 기반 다지기: "누구에게, 무엇을"
- **목표:** 포지셔닝 확정 + 발행 습관 형성. 아직 수익보다 *일관성*이 핵심.
- 실행:
  - 브랜드 키트 작성 (타깃 오디언스 1명을 구체적으로, 콘텐츠 기둥 3개, 톤)
  - 메인 플랫폼 1개 + 보조 1개 선택 (예: YouTube + 뉴스레터)
  - 주 2~3회 발행. 아이디어 인박스를 항상 5개 이상 채워두기
  - "빌드 인 퍼블릭" — 과정 자체를 콘텐츠로
- **지표:** 발행 수, 팔로워/구독자 증가, 저장·공유율

### Phase 2 (31–60일) — 오디언스 & 첫 수익
- **목표:** 첫 1원을 만든다. 작아도 된다(제휴·디지털 상품).
- 실행:
  - 가장 반응 좋았던 콘텐츠 주제를 더블다운
  - 무료 리드 마그넷(체크리스트/템플릿)으로 이메일 리스트 구축
  - 첫 수익원 1개 가동: 제휴 링크 또는 저가 디지털 제품(₩5,000~30,000)
  - 모든 수익을 **수익 추적**에 기록 → 무엇이 통하는지 측정
- **지표:** 이메일 구독자, 첫 매출, 수익원별 전환

### Phase 3 (61–90일) — 수익화 시스템화
- **목표:** 반복 가능한 수익 구조 + 단가 상승.
- 실행:
  - 잘 팔린 제품을 시리즈/번들/구독으로 확장
  - 협찬·강의 등 고단가 수익원 1개 추가
  - 콘텐츠 → 리드 → 제품으로 이어지는 퍼널을 문서화
  - 월 단위로 대시보드 목표(수익·발행) 리뷰 후 다음 분기 목표 상향
- **지표:** 월 반복 수익(MRR 성격), 객단가, 수익원 다변화

## 🔁 주간 운영 리듬 (앱과 함께)

1. **월요일 — 기획:** 아이디어 인박스 점검, 이번 주 콘텐츠를 파이프라인 "제작 중"으로
2. **화~목 — 제작/발행:** 제작 완료 → "예약됨" → 발행 후 "발행됨" + 링크 기록
3. **금요일 — 측정:** 수익 기록 업데이트, 대시보드 체크리스트 확인
4. **매월 말 — 리뷰:** 6개월 추이 보고 잘 된 수익원 더블다운, 목표 재설정

## 🛠 기술 메모

- 순수 HTML/CSS/JS, 의존성 0. 빌드 단계 없음.
- 상태는 `localStorage`(`content-studio-v1`)에 저장.
- `index.html` · `styles.css` · `app.js` 세 파일로 구성.
